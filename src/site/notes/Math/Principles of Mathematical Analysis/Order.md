# Order
> [!example] Definition of order
> Let $S$ be a set. An oreder on $S$ is a relation, denoted by $<$, with the two following properties:
> (i) if $x \in S$ and $y \in S$ then one and only one of the statements are ture
> $$
> x<y\ \ \ x=y \ \ \ x>y
> $$
> (ii) If $x,y,z\in S$, if $x<y$ and $y<z$, then $x<z$.
>

# Set
Here are some terminology of set theory

> [!example] Definition 
> Suppose $A$ is any set, we write $x \in A$ to indicate $x$ is a member of $A$ and $x \not\in A$ to indicate $x$ is not a member of $A$.
> 
> The set which does not contain any element will be called the empty set. If a set has at least one element, it is called nonempty
> 
> If $A$ and $B$ are sets, and if every element of $A$ is an element of $B$, we say that $A$ is a subset of $B$, and write $A\subset B$ or $B\supset A$. If, in addition, there is an element of $B$ which is not in $A$, then $A$ is said to be a proper subset of $B$. Note that $A\subset A$ for evert set $A$.
> 
> If $A\subset B$ and $B\supset A$, we write $A=B$. Otherwise $A\neq B$.

> [!example] Definition of [[Math/Principles of Mathematical Analysis/Order\|ordered]] set
> An ordered set is a set where an order is defined.

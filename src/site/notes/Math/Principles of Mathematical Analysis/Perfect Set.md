# Perfect Set
> [!example] Definition of perfect set
> $E$ is perfect if $E$ is [[Math/Principles of Mathematical Analysis/Closed Set\|closed]] and if every point of $E$ is a [[Math/Principles of Mathematical Analysis/Limit Point\|limit point]] of $E$

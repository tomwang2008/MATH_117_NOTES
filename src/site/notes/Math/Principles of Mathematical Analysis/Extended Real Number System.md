# The Extended Real Number System
> [!example] Definition of the extended real number system
> The extended real number system contains the real number [[Math/Principles of Mathematical Analysis/Fields\|field]] $\mathbb{R}$  and two symbols, $- \infty$ and $\infty$. We preserve the original order in $\mathbb{R}$ and define 
> $$
> -\infty<x<\infty
> $$
> for every $x$.

Notice that the extended real number system does not form a field, but it is customary to make the following conventions

> [!example] Definition of addition and multiplication
> (a) If $x$ is real then
> $$
> x+\infty=\infty ,\ \ \  x-\infty=-\infty ,\ \ \  \frac{x}{+\infty}=\frac{x}{-\infty}=0
> $$
> (b) If $x>0$ then $x\cdot+\infty=+\infty$ and $x\cdot(-\infty)=-\infty$.
> (c) If $x<0$ then $x\cdot+\infty=(-\infty)$ and $x\cdot(-\infty)=+\infty$.

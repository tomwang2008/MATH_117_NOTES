# $F^{m,n}$

>[!example] Definition of $\mathbf{F}^{m,n}$
>For positive integers $m$ and $n$ the set of all $m-\text{by}-n$ matrices with entries in $\mathbf{F}$ is denoted by $\mathbf{F}^{m,n}$.

The statement below should be intuitive

>[!info] $\dim{\mathbf{F}^{m,n}}=mn$
>The dimension of $\mathbf{F}^{m,n}$ is $mn$.
>
>Proof:
>
>Easy to verify that a list of matrices has all 0 except for a 1 for one entry is a [[Math/Linear Algebra Done Right/Basis\|basis]] for this vector space.
>
>$\blacksquare$

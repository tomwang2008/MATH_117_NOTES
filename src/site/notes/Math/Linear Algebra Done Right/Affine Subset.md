# Affine Subset

>[!example] Definition of affine subset
>An affine subset of [[Math/Linear Algebra Done Right/Vector Space\|$V$]] is the set of $V$ of the form [[Math/Linear Algebra Done Right/v+U\|v+U]] for some $v\in V$ and some [[Math/Linear Algebra Done Right/Subspace\|subspace]] $U\in V$.

 >[!example] Definition of Parallel
 >For $v\in V$ and subspace $U$ in $V$, the affine subset $v+U$ is said to be parallel to $U$.

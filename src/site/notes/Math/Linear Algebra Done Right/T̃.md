# $\tilde{T}$

>[!example] $\tilde{T}$
>Suppose $T\in \mathcal{L}(V,W)$. Define $\tilde{T}\text{ }: \text{} V/\text{null }T\to W$ by
> $$
> \tilde{T}(v+\text{null }T)=Tv
> $$

Suppose $T\in \mathcal{L}(V,W)$ Then
(a) $\tilde{T}$ is a linear map from $V/\text{null }T$ to $W$
(b) $\tilde{T}$ is [[Math/Linear Algebra Done Right/Injectivity\|injective]] 
(c) $\text{range }T=\text{range }\tilde{T}$
(d) $V/\text{null }T$ is [[Math/Linear Algebra Done Right/Isomorphism\|isomorphic]] to $\text{range }T$

# Diagonal Matrix
>[!example] Definition of diagonal matrix
>A diagonal [[Math/Linear Algebra Done Right/Matrices\|matrix]] is a square matrix that is 0 everywhere except possibly along the [[Math/Linear Algebra Done Right/Diagonal of a Matrix\|diagonal]].

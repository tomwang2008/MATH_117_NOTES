# $\pi$

>[!example] Definition of quotient map
>Suppose $U$ is a [[Math/Linear Algebra Done Right/Subspace\|subspace]] of [[Math/Linear Algebra Done Right/Vector Space\|$V$]]. The quotient map $\pi$ is the linear map $\pi\ : \ V \to \text{ }$[[Math/Linear Algebra Done Right/Quotient Space\|$V/U$]] defined by
> $$
> \pi(v)=v+U
> $$
> for $v\in V$

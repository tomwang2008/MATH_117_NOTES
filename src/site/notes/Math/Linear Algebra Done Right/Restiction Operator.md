# $T\big|_{U}$

>[!info] Definition of restriction operator
>Suppose [[Math/Linear Algebra Done Right/Linear Map\|$T$]] $\in$ [[Math/Linear Algebra Done Right/L(V)\|L(V)]] and $U$ is a [[Math/Linear Algebra Done Right/Subspace\|subspace]] of [[Math/Linear Algebra Done Right/Vector Space\|$V$]] [[Math/Linear Algebra Done Right/Invariant Subspace\|invariant]] under $T$. The restriction operator $T\big|_{U}$ is defined by 
> $$
> T\big|_{U}u=Tu
> $$
> For $u \in U$.

# $T/U$

>[!info] Definition of quotient operator
>Suppose [[Math/Linear Algebra Done Right/Linear Map\|$T$]] $\in$ [[Math/Linear Algebra Done Right/L(V)\|L(V)]] and $U$ is a [[Math/Linear Algebra Done Right/Subspace\|subspace]] of [[Math/Linear Algebra Done Right/Vector Space\|$V$]] [[Math/Linear Algebra Done Right/Invariant Subspace\|invariant]] under $T$. The quotient operator $T/U$ is defined by 
> $$
> T/U(v+U)=Tv+U
> $$
> For $v\in V$

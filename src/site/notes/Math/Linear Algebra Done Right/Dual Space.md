# Dual Space

>[!example] Definition
>A dual space of [[Math/Linear Algebra Done Right/Vector Space\|$V$]], denoted $V'$ is the vector space of all [[Math/Linear Algebra Done Right/Linear Functional\|linear functional]] of $V$. In other words, $V'=\mathcal{L}(V,\mathbf{F})$.

>[!info] [[Math/Linear Algebra Done Right/Dimension\|Dimension]] of a dual space
>Suppose $V$ is [[Math/Linear Algebra Done Right/Finite-dimensional Vector Space\|finite-dimensional vector space]], then $V'$ is also finite-dimensional and $\text{dim }V=\text{dim }V'$.
>
>Proof:
>
>By the definition and the note [[Math/Linear Algebra Done Right/L(V,W)\|L(V,W)]] we get the desirded.
>
>$\blacksquare$

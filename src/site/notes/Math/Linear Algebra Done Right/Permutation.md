# Permutation
> [!example] Definition of permutation
> A permutation of $(1,\dots,n)$ is a list $(m_{1},\dots,m_{n})$ that contains each of the numbers $1,\dots,n$ exactly once.
> 
> The set of all permutations of $(1,\dots,n)$ is denoted $\text{perm }n$.
>

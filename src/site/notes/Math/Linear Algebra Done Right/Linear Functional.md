# Linear Functional

>[!example] Definition
>A linear functional on [[Math/Linear Algebra Done Right/Vector Space\|$V$]] is a [[Math/Linear Algebra Done Right/Linear Map\|linear map]] from $V$ to $\mathbf{F}$. In other words, a linear functional is an element of [[Math/Linear Algebra Done Right/L(V,W)\|$\mathcal{L}(V, \mathbf{F})$]].

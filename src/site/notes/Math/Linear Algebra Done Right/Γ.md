# $\Gamma$

The [[Math/Linear Algebra Done Right/Linear Map\|linear map]] $\Gamma$ is defined by the following

>[!example] Definition of $\Gamma$
>The linear map $\Gamma:V_{1}\times\dots \times V_{n}\to V_{1}+\dots +V_{n}$ is defined by 
> $$
> \Gamma(v_{1},\dots,v_{n})=v_{1}+\dots+v_{n}
> $$ 


>[!info] Product and [[Math/Linear Algebra Done Right/Direct Sum\|direct sum]] 
>The sum of [[Math/Linear Algebra Done Right/Subspace\|subspaces]] $U_{1}+\dots+U_{n}$ where $U_{1},\dots,U_{n}\in V$ is a direct sum if and only if $\Gamma$ is injective.
>
>Proof:
>
>First, suppose $U_1 + \dots + U_m$ is a direct sum.
>Consider any element $(u_1, \dots, u_m)$ in $\text{null }\Gamma$.
>By the definition of $\Gamma$, this means:
>$$u_1 + \dots + u_m = 0$$
>Because the sum is direct, the only way to write $0$ as a sum of vectors from $U_j$ is if each vector is $0$
>Therefore, $u_1 = 0, \dots, u_m = 0$.
>This proves that $\text{null }\Gamma = \{ (0, \dots, 0) \}$, which implies that $\Gamma$ is injective.
>Conversely, suppose $\Gamma$ is [[Math/Linear Algebra Done Right/Injectivity\|injective]].
>Consider the equation:
$$u_1 + \dots + u_m = 0$$
>Applying the definition of $\Gamma$, this equation is equivalent to:
$$\Gamma(u_1, \dots, u_m) = 0$$
>Since $\Gamma$ is injective, the only element in its null space is the zero vector.
>Therefore, $(u_1, \dots, u_m) = (0, \dots, 0)$, which means each $u_j = 0$.
>Thus, by definition, the sum is a direct sum. 
>
>$\blacksquare$

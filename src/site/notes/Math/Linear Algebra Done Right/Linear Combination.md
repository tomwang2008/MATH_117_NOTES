# Linear Combination

> [!example] Definition of Linear Combination
> A linear combination of a list of vectors $v_1,\dots , v_n$ in V is a a vector in the form of 
> $$a_1v_1+\dots +a_nv_n$$
> Where $a_1,\dots,a_n \in F$
